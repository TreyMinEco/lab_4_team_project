## 📌 Опис проєкту
Програма призначена для роботи з текстовими файлами (`TF9_1.txt` та `TF9_2.txt`).  

Основне завдання проєкту — зчитати рядки з першого текстового файлу та вирівняти/форматувати їх у другому файлі за наступним правилом:
* 🔹 Якщо довжина рядка **менше 20 символів** — доповнити його пробілами справа до 20 символів.
* ✂️ Якщо довжина рядка **більше 20 символів** — обрізати його до перших 20 символів.

Також програма виводить вміст підготовленого файлу з вказівкою довжини кожного рядка.

---

## 🔧 Основний функціонал
Програма дозволяє:
* 📁 Безпечно відкривати файли з обробкою можливих помилок доступу/відсутності файлу.
* ✍️ Записувати початкові дані у перший файл (`TF9_1.txt`).
* 🔄 Читати дані з файлу `TF9_1.txt`, форматувати кожен рядок до 20 символів та зберігати у `TF9_2.txt`.
* 📊 Виводити підсумковий вміст файлу `TF9_2.txt` у консоль з точним вимірюванням довжини рядків.
* 🔒 Коректно закривати файли після завершення читання або запису.

## 👨‍💻 Командна розробка
Проєкт розробляється спільно з використанням Git та GitHub.

**Основна гілка проєкту:** `main`

Кожен учасник виконує свою частину роботи у власній гілці.

### Робочий процес
1. Отримати призначене завдання через **GitHub Issues**.
2. Створити окрему гілку від `main`.
3. Реалізувати необхідні зміни.
4. Перевірити роботу програми.
5. Створити `commit` та виконати `push` своєї гілки на GitHub.
6. Створити **Pull Request** до `main`.
7. Дочекатися перевірки тімліда та рецензії колег.
8. За необхідності внести виправлення.
9. Після схвалення виконати **Merge** до `main`.
